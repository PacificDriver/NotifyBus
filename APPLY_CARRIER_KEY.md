# 🔑 Настройка API Перевозчика

> **⚠️ ВАЖНО:** Настройки API перевозчика теперь хранятся в базе данных и настраиваются через админ-панель.  
> Переменные окружения `.env` больше не используются для этих настроек.

## Способ 1: Через админ-панель (рекомендуется)

### 1. Войти в админ-панель

```
http://your-domain.com/admin/settings
```

### 2. Перейти на вкладку "🚌 API Перевозчика"

### 3. Ввести настройки:

- **API URL**: `http://rc.rfbus.ru:8086`
- **API Key (x-access-token)**: Ваш токен доступа
- **Timeout (секунды)**: `120` (рекомендуется для больших запросов)

### 4. Нажать "💾 Сохранить настройки"

Настройки сохранятся в базе данных с шифрованием для секретного ключа.

### 5. Проверить подключение

Нажмите кнопку "🔍 Проверить подключение" для проверки корректности настроек.

## Способ 2: Через .env файл (устарело, только для начальной настройки)

> **Примечание:** Этот способ больше не рекомендуется, но может использоваться для первоначальной настройки, если админ-панель недоступна.

### 1. Добавить ключ в .env

```bash
# Открыть .env файл
nano /var/www/html/NotifyBus/.env

# Добавить или изменить (эти значения больше не используются):
CARRIER_API_URL=http://rc.rfbus.ru:8086
CARRIER_API_KEY=ваш_ключ_здесь
CARRIER_API_TIMEOUT=120
```

### 2. Очистить кэш конфигурации

```bash
cd /var/www/html/NotifyBus

# Очистить кэш конфигурации (ВАЖНО!)
sudo -u www-data php artisan config:clear
```

⚠️ **Важно:** После этого необходимо настроить настройки через админ-панель, так как система теперь использует значения из базы данных.

## Какой способ использовать?

- **Админ-панель** ✅ - **Рекомендуется** для всех случаев
- **.env файл** ⚠️ - Только для первоначальной настройки, если админ-панель недоступна

## Преимущества использования админ-панели

1. ✅ Настройки хранятся в БД с шифрованием
2. ✅ Не требуется доступ к серверу для изменения настроек
3. ✅ Не нужно перезапускать сервисы или очищать кэш
4. ✅ Можно проверить подключение прямо в интерфейсе
5. ✅ Безопасное хранение секретных ключей

## Проверка работы

### Через админ-панель:

1. Перейдите в `/admin/settings`
2. Вкладка "🚌 API Перевозчика"
3. Нажмите "🔍 Проверить подключение"

Если подключение успешно, вы увидите сообщение с количеством полученных станций.

### Синхронизация станций:

1. После успешной проверки подключения
2. Нажмите "🔄 Обновить станции"
3. Дождитесь завершения синхронизации (может занять до 3 минут)

## Технические детали

- Настройки хранятся в таблице `settings` с ключами:
  - `carrier_api_url` - URL API
  - `carrier_api_key` - Ключ доступа (зашифрован)
  - `carrier_api_timeout` - Таймаут запросов
- Секретные данные (ключ API) шифруются автоматически при сохранении
- Система автоматически использует настройки из БД при каждом запросе

## Устранение проблем

### Ошибка "API ключ не настроен"

1. Проверьте, что вы сохранили настройки в админ-панели
2. Убедитесь, что ключ API введен правильно (не замаскирован)
3. Проверьте логи: `tail -f storage/logs/laravel.log`

### Ошибка "Превышен лимит времени ожидания"

1. Увеличьте значение "Timeout" в настройках до 120 секунд
2. Проверьте доступность API сервера
3. Проверьте сетевые подключения

### Настройки не применяются

1. Убедитесь, что вы нажали "Сохранить настройки"
2. Проверьте, что вы вошли в систему как администратор
3. Проверьте логи на наличие ошибок
